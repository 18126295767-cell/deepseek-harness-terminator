Additional walkthrough JPEGs under `assets/screenshots/` are 1153x768
credential-free UI captures. The API-key fields are blank by design; their
SHA-256 values are recorded in the release review before publication.

The macOS App image preserves the source screen resolution instead of
artificially upscaling it. Both images show an empty session and were visually
reviewed for accounts, credentials, API keys, user sessions, private paths,
and personal content before inclusion.

The Windows screenshots were generated by `scripts/capture-windows-ui.mjs` on
GitHub Actions `windows-2025` at 1600x1000. The script used a fresh headless
Chromium context, permitted only the loopback DSH URL, and wrote
`windows/windows-screenshot-proof.json` with the runner, commit, dimensions,
byte sizes, and SHA-256 values. All five images were downloaded and visually
reviewed for credentials, accounts, sessions, private paths, clipping, and
layout errors before being included in the public documentation.
